# Unitree Skill Marketplace Analysis

Unitree's humanoid robot app-store announcement is an external validation signal for the ETD direction: robot value is moving from hardware-only performance to downloadable, reusable and community-extensible capabilities.

## Key distinction

Unitree's public direction appears consumer/developer-first: Action Library, Datasets, mobile app sync and community uploads.

ETD is positioned as an industrial-grade equivalent:

- validated skill packages;
- capability policies;
- station compatibility;
- failure scenario testing;
- release artifacts;
- enterprise / workflow integration;
- strict application-layer boundaries.

## Implication for ETD

The prototype should include a marketplace layer, but with governance that is stricter than a consumer app store because physical robot motion can create real-world risk.
